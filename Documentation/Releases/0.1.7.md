# Arc Kit 0.1.7

修复部分 Mac 上搜狗输入源被误判为不可用的问题，并为菜单栏收纳增加首次选择引导和逐项限制提示。

## 输入法：准确区分配置与当前会话

- 系统重复返回完全相同的输入源时，按一个输入源处理，避免重复登记导致“应用更改”不可用或名称重复。
- 分别显示已配置的输入源和当前会话是否启用；勾选表示保留，不代表正在使用。同一输入法的多个已配置模式仍作为一组保留。
- 显示、应用前复核与处理结果使用同一套匹配规则。身份或启用状态冲突时提示无法确认，不猜测为可用。

仍由用户决定保留哪些输入法，默认保留全部现有项。不自动注销、重启输入法或移除英文键盘。

## 菜单栏：先选择，再收起

- macOS 27 上，收纳名单为空时，页面显示“尚未选择收纳应用”；点击左侧三点会进入管理页，不再表现为点击后没有反应。
- 空名单不启动自动收起计时。选好应用并点击“应用更改”后，按设定时长重新计时；默认仍为 5 分钟，可在设置中调整或关闭。
- 系统将某个图标与其他应用关联登记、或无法确认收纳身份时，提前说明原因并禁止加入收纳；仍可排序或移回常驻。
- 窄窗口首次设置优先显示可选的常驻应用；应用及撤销前重新核对新增收纳目标。

现有收纳名单、自动收起设置和系统图标顺序保留，不根据另一台 Mac 的设置替用户选择收纳对象。

## 下载与升级

版本为 **0.1.7 / build 90**，支持 macOS 13 及以上的 Apple Silicon 和 Intel Mac；菜单栏编排与上述直接收纳流程需要 macOS 27。通过应用内“检查更新”，或下载 `ArcKit-universal.dmg` / `ArcKit-universal.zip`，正常退出后整包替换。build 89 候选用户也可升级。

从 0.1.6 升级没有新增数据库迁移，配置 JSON 契约仍为 **33**。保留现有数据，本地剪贴板不变，iCloud 同步仍不开放。

## 验证范围与已知情况

同功能候选已在第二台 macOS 27.0.1 设备保留数据安装；只读诊断确认重复登记的搜狗模式被正确识别为一个可用目标。菜单栏空名单、限制提示、计时及撤销已通过隔离回归和页面检查；该设备上的实际收起／展开、自动收起，以及真实输入源写入和重新登录持久性尚未完成验收。

候选首次启动曾遇到 macOS 的 `Launch Constraint Violation`，导致后台无法启动；正常退出并刷新已安装应用及后台组件的系统注册后恢复。更新时的注册／签名约束问题仍可能出现；若升级后窗口或鼠标后台不可用，请保留技术详情并反馈。

安装包由 GitHub Actions 构建，使用 ad-hoc 签名，没有 Apple Developer ID 签名或公证。安装包摘要见 `SHA256SUMS.txt`；Sparkle 更新包和订阅使用 Ed25519 签名。
