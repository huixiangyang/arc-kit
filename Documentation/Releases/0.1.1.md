# Arc Kit 0.1.1

本次更新重点修复多屏窗口落点错误，并加入可保存和恢复的窗口场景。

## 窗口管理

- 修复后台长期运行后仍使用旧屏幕排列或分辨率的问题。窗口布局与场景统一读取实时屏幕快照，屏幕切换尚未完成时取消布局，避免误移到其他屏幕。
- 修复跨屏拖拽吸附的预览与实际落点不一致：按松手点锁定目标屏，目标屏断开或几何发生变化时取消本次吸附。
- 新增「窗口 → 场景」：保存当前布局、编辑匹配规则、更新布局、另存为、显示器重映射及快捷键；也可从菜单栏和应用内 `⌘K` 应用场景。
- 场景按应用与窗口身份唯一匹配，分别报告缺屏、缺窗口、歧义和应用尺寸限制；部分恢复失败时保留已尝试窗口的撤销点。更新布局保留暂时不可用的旧条目，不自动删除副屏预设。

## 壁纸与数据

- 壁纸同词刷新按来源替换结果，失败来源保留旧内容；配置冲突后可重新读取并重试。
- 重复导入可修复缺失媒体或损坏缩略图，同时保留收藏与分屏分配；失败导入不会删除其他条目的共享缩略图。
- 桌面视频换片、重连及回滚继承暂停状态；停止或失败后不再被迟到事务恢复。播放失败释放资源，不再误报成功。
- 备份与恢复检查图库、背景和资产索引的路径及大小关联，拒绝业务引用错配的备份。

## 下载与升级

版本为 **0.1.1 / build 62**，支持 macOS 13 及以上的 Apple Silicon 和 Intel Mac。使用应用内“检查更新”，或下载 `ArcKit-universal.dmg` / `ArcKit-universal.zip` 安装；替换前正常退出 Arc Kit。

本版增加窗口场景的数据表，升级时自动迁移，保留已有配置。建议先备份完整数据；若需退回旧版，应使用升级前匹配的数据库备份。配置 JSON 契约升至 24，窗口 IPC 升至 7，主应用与后台必须整包升级。

安装包由 GitHub Actions 构建，使用 ad-hoc 签名，**没有 Apple Developer ID 签名或公证**。macOS 可能要求重新确认打开、辅助功能或后台运行权限。安装包摘要见 `SHA256SUMS.txt`；Sparkle 更新包与订阅使用 Ed25519 签名校验。

## 验证范围与已知限制

- 已在三屏布局中验证最大化、台前调度布局和跨屏切换，并独立读取 WindowServer 的实际窗口位置；包含位于主屏上方的负坐标屏幕。
- 跨屏吸附的目标固定、断屏和几何变化取消有行为回归；物理热插拔、真实鼠标跨屏拖拽，以及场景批量恢复与撤销的完整桌面验收尚未覆盖。
- 场景不会启动缺失应用、打开文档、跨 Space 移动窗口或退出全屏，也不会在显示器重连时自动恢复。
- 部分应用限制窗口尺寸或控制；iCloud Drive 的 Finder 原生右键菜单不保证出现，可使用 Finder 工具栏入口。
- ad-hoc 跨版本升级后的权限保留与后台注册仍受 macOS 管理；若后台未启动，先检查系统的后台项目与辅助功能授权。
