# Arc Kit 0.1.4

这次更新加入菜单栏图标收纳、编排和搜索。把不常用图标收入一组，平时点击 Arc Kit 左侧三点展开或收起；按住 ⌘ 拖动调整顺序后，收纳选择仍会保留。

## 菜单栏图标编排

- 在“菜单栏 → 编排图标”开启收纳，将图标设为常驻或收纳，再点击“应用排列”。行右侧按钮只改归属；列表拖放和右键移动可调整真实菜单栏顺序。
- 收纳名单独立保存，并随设置和完整数据备份保存。系统 ⌘ 拖动只改变顺序，不再因位置变化丢失收纳目标。
- 草稿应用前核对当前图标与排列，防止覆盖面板外的新变化；支持撤销未应用更改及最近一次应用。
- 同一应用的多个图标一起收纳，顺序可分别调整。支持系统输入法菜单（包括搜狗）和可唯一识别的 SCVPN 等 root 应用图标；时钟、控制中心及身份不明的项目保持只读。

编排入口需要 **macOS 27**。收纳直接隐藏所选应用图标，不靠占位挤入系统溢出区；显示全部、关闭收纳或退出 Arc Kit 会恢复本次隐藏的项目。隐藏输入法菜单不会停用输入法，但切换输入源后同一个系统菜单仍按收纳选择显示。

## 一个组合入口，独立搜索与快捷键

- 三点与品牌标志属于同一个菜单栏项目，⌘ 拖动时整体移动。左侧三点切换收纳，右侧品牌或右键打开窗口、鼠标、Finder、壁纸等工具面板。
- 快捷面板不再重复显示图标管理区；编排和查找集中在主窗口“菜单栏”页。
- 关闭收纳也能搜索全部图标；可从“查找图标”、⌘K 或独立搜索快捷键进入。
- 支持录制搜索、展开／收起、显示全部快捷键。重复组合或系统注册冲突会明确反馈；录制时暂停本功能快捷键，避免误触发。
- 图标菜单请求只发送一次，失效或超时后不自动重放；显示器、Space 和休眠变化时先恢复图标，再等待环境稳定。

## 下载与升级

版本为 **0.1.4 / build 86**，支持 macOS 13 及以上的 Apple Silicon 和 Intel Mac。使用应用内“检查更新”，或下载 `ArcKit-universal.dmg` / `ArcKit-universal.zip`；替换前正常退出 Arc Kit，主应用、后台与 Finder 扩展整包升级。

升级保留已有设置和素材。配置 JSON 契约升至 **31**，旧版本 JSON 配置不再导入；完整数据库备份通过迁移恢复。升级前建议保留完整备份，回退时使用与旧版匹配的数据库。使用早期 0.1.3 开发版时，若旧分区在升级前已经失效，请在编排页重新选择收纳项目，无需恢复旧顺序。未正式发布的 Agent 会话功能已移除，不删除开发版已有会话记录或资产。

安装包由 GitHub Actions 构建，使用 ad-hoc 签名，**没有 Apple Developer ID 签名或公证**。macOS 可能要求重新确认打开、辅助功能或后台运行权限。安装包摘要见 `SHA256SUMS.txt`，Sparkle 更新包与订阅分别使用 Ed25519 签名校验。

## 验证范围与限制

macOS 27 已完成真实图标编排、收起、显示全部、退出恢复和重启后收起检查；收纳名单持久化与系统排序解耦有隔离回归。多屏热插拔、Space、休眠恢复、更多多图标应用及第三方原生菜单取用仍需进一步实机覆盖。

macOS 13–26 保留离屏收纳路径，尚未完成对应系统的完整实机验收；深度收纳与普通区筛选不在 macOS 27 开放。菜单栏系统外观设置暂不提供。刘海屏或常驻图标本身放不下时，macOS 自身仍可能显示溢出入口。
