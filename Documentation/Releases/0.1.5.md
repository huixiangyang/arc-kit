# Arc Kit 0.1.5

这次更新让菜单栏在空闲时自动收起，并为 Arc Kit 菜单栏标志加入彩色渐变与轻量流光。

## 空闲后自动收起

在“菜单栏 → 更多设置”中控制“空闲后自动收起”，并调整等待时间。默认开启、默认 **5 分钟**，可选择 **1–60 分钟**；设置保存后立即生效，重启后保留。

- 图标展开后，连续达到设定时长没有键盘、鼠标或触控板操作，就会自动收起；任何应用中的输入都会重新计算空闲时间。
- 手动展开、修改等待时间或环境恢复后，重新等待完整时长。关闭开关会取消计时，不影响手动展开／收起，也不主动展开已收起图标。
- 收纳主开关关闭时不执行；休眠、显示环境恢复以及正在应用排列、取用图标或录制快捷键时不抢占操作。
- 继续使用已有收纳名单与恢复流程，不改变图标排序。只读取当前会话的输入空闲秒数，不记录按键内容。

## 彩色标志与流光

菜单栏拱形采用珊瑚橙—玫紫渐变、暖金断角和细边高光。每轮流光播放 2 秒，随后静置 6 秒；三点、位置及尺寸保持不动，左侧收纳、右侧工具面板和整体拖动方式不变。

动效使用缓存位图原生换帧，不加载 GIF。应用或系统开启减少动态效果时显示静态彩色标志；打开菜单、收纳切换、隐藏入口、退出、休眠、息屏及切换用户时暂停。

## 下载与升级

版本为 **0.1.5 / build 87**，支持 macOS 13 及以上的 Apple Silicon 和 Intel Mac；macOS 27 使用直接隐藏收纳路径。使用应用内“检查更新”，或下载 `ArcKit-universal.dmg` / `ArcKit-universal.zip`，正常退出后整包替换主应用、后台和 Finder 扩展。

升级保留设置、素材、收纳名单及系统图标顺序，旧数据库自动补充自动收起的默认值。配置 JSON 契约升至 **32**，旧版本 JSON 配置不再导入；完整数据库备份通过迁移恢复。回退时使用与旧版匹配的数据备份。

安装包由 GitHub Actions 构建，使用 ad-hoc 签名，没有 Apple Developer ID 签名或公证。macOS 可能要求重新确认打开、辅助功能或后台运行权限。安装包摘要见 `SHA256SUMS.txt`；Sparkle 更新包与订阅分别使用 Ed25519 签名校验。

## 验证范围与限制

已验证自动收起的配置、空闲计时、取消及恢复边界，动效逐帧、静置、入口切换及暂停后的迟到回调，并检查离屏菜单栏尺寸和 GIF 预览。完整双架构产物由 Release 工作流生成。

多屏热插拔、Space、休眠恢复及 macOS 13–26 收纳路径仍需扩大实机覆盖。第三方图标菜单的实际显示结果仍取决于应用自身的辅助功能支持。
