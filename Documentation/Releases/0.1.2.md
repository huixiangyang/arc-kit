# Arc Kit 0.1.2

本次更新修复 UU 远程中外置鼠标滚动正常、触控板纵向方向仍相反的问题。

## UU 远程滚动

- 默认应用规则改为“仅反转触控纵向”：普通鼠标及不带手势标记的高分辨率滚轮保持原样，只反转触控板上下滚动。
- 保留系统惯性、手势起止、横向滚动、修饰键及事件目标，不给触控板叠加鼠标平滑或加速。带原生手势标记的 Magic Mouse 也使用这条规则。
- 其他应用维持原来的滚动处理。可在“鼠标 → 应用规则”将 UU 改为“不启用增强”，让所有输入原样通过。
- 旧安装中仍采用“不启用增强”和默认参数的原始 UU 规则会一次性升级。自建规则、已修改的行为或参数、已删除的规则，以及用户填写或清空的说明均保留。

## 下载与升级

版本为 **0.1.2 / build 63**，支持 macOS 13 及以上的 Apple Silicon 和 Intel Mac。使用应用内“检查更新”，或下载 `ArcKit-universal.dmg` / `ArcKit-universal.zip`；替换前正常退出 Arc Kit，主应用与后台整包升级。

升级保留已有配置与素材。配置 JSON 契约升至 25，旧 JSON 配置不再导入；完整数据库备份通过迁移恢复。建议升级前保留完整数据备份，回退时使用与旧版匹配的数据库。

安装包由 GitHub Actions 构建，使用 ad-hoc 签名，**没有 Apple Developer ID 签名或公证**。macOS 可能要求重新确认打开、辅助功能或后台运行权限。安装包摘要见 `SHA256SUMS.txt`，Sparkle 更新包与订阅使用 Ed25519 签名校验。

## 验证范围与限制

触控纵向反转、原生手势与惯性字段保留、鼠标滚轮放行、规则修改与删除、旧配置升级均有隔离回归。远程软件版本以及两端设置会影响实际方向，真实设备和远程会话中的最终效果仍需确认。此规则不修改 macOS“自然滚动”或 UU 内部设置。
