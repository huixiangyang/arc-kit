# 版本说明

## 0.1.0 · build 56（首个公开版本）

- 增加 GitHub 源码、官网下载和 GitHub Actions 发行流程；安装包使用 ad-hoc 签名，不做 Apple 公证。
- 源码采用 MIT 许可证；Office 空白模板由仓库脚本生成，iWork/WPS 模板改为用户自行导入。
- 软件更新改用 Sparkle 2.10.0，支持自动检查、下载、签名校验、安装重启与可选的退出时安装。
- 官网版本信息与签名更新订阅由同一次 Release 自动生成。完整发行说明见 [0.1.0](Releases/0.1.0.md)。
- XPC 写入显式使用已校验的非空载荷指针，修复 Xcode 26 CI 的 C 接口类型检查失败；请求大小和空载荷校验保持在编码器入口。

以下 build 是公开发行前的开发候选版本。构建与分发见[交付](交付.md)，尚未完成的实机验收见[规划](规划.md)。

- 官网、关于页与中英文隐私说明统一使用 `arc-kit.com`。
- 公开文档移除个人设备和安装现场记录，保留已知限制与可复现命令；公开源码使用经过审查的首次提交。
- CI 分开标明离线回归与需要活动显示器的 AppKit / CVDisplayLink 验收。
- 发布前验证版本 Tag、三组件版本、源码修订及双架构产物，先上传 Release 附件，再发布签名订阅与官网版本信息。

## 0.1.0 · build 55

- 修正 build 54 仍将菜单代理激活误认为窗口前台的问题，来源改由实际键盘接收应用的 KVO 变化维护。
- 菜单关闭共用真实前台变化，不再因代理激活通知立即收起；展开时前台与点击来源不一致则拒绝捕获。
- 保留点击时间与窗口令牌的绑定，菜单诊断增加有界的前台 PID 时间线，不记录窗口内容。
- 相关回归与完整构建用于验证代码，远程和台前调度中的真实点击、布局仍需实机确认。

## 0.1.0 · build 54

- 菜单栏按原始点击时间固定应用来源，避免转发期间把 Arc Kit 自身当作目标；重复或迟到输入不能覆盖来源。
- 捕获失败、功能关闭和服务未就绪时直接展示具体原因，菜单尺寸保持稳定。
- 相关窗口与通信回归及中英文资源校验通过；普通点击、远程输入与多屏布局的实际效果仍待确认。

## 0.1.0 · build 53

- 功能聚合到 `Sources/Features`；Application 负责装配、导航及全局管理，Platform 保留系统基础能力，通用控件归 UI。
- Finder、窗口、鼠标设置通过功能配置投影编辑，继续共用事务、撤销历史与保存回执。
- 壁纸和外观解耦，数据库与跨功能动作显式注入；素材交付等待保存结果。
- Host 分离入口、编排与只读配置，仍保持单一后台及原有编译隔离。
- 修复切换语言后会话未跟进已提交配置代次、造成后台持续失联的问题；界面偏好和规则说明仍不触发后台重连。

已完成开发安装与三种语言选项（跟随系统、简体中文、English）切换后的通信检查。真实鼠标、Finder 文件动作及多屏场景的完整覆盖仍在规划中；ad-hoc 更新后的首次后台启动约束问题尚未根治。

## 0.1.0 · build 52

- 鼠标应用规则按默认行为和应用单独设置组织，行内选择模式，仅自定义模式展示参数，显示实际应用图标。
- 规则增加可编辑、可清空的说明；UU 预置说明解释避免重复翻转的原因。
- 说明编辑不推进后台代次；SQLite 一次性迁移保留既有规则，配置 JSON 契约升至 23。

## 0.1.0 · build 51

- 通用设置增加菜单栏图标开关；隐藏后仍可从 Spotlight 或应用程序打开设置。
- UU 远程默认不启用滚动增强，用户可修改或删除。旧库只补一次缺失规则，保留自定义设置，删除后不自动添加。

## 0.1.0 · build 49–50

- 增加六款柔光主题、深浅配色、个人配方、图片取色、导入导出、日夜规则及节能暂停。
- 背景重置保留个人主题与收藏；恢复备份在临时数据库中迁移、验证，再替换当前数据。
- build 50 的菜单栏图标实验已撤回，继续使用原有品牌图标。

## 0.1.0 · build 48 及之前

- 本地化统一使用 Apple String Catalog、原生访问器与 Foundation 插值、复数和格式化。
- 配置与资源索引集中到 `~/.arc-kit/app.sqlite`，应用负责有序迁移、备份恢复及唯一写入；后台只读已提交配置。
- Finder、窗口与鼠标合并到统一 Runtime Host；文件 Worker 按任务启动，退出主应用时注销后台。
- 修正鼠标事件字段及目标路由、窗口前台目标捕获、Finder 菜单与执行链路。历史场景验证不替代新版本的真实设备验收。
