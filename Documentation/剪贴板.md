# 本地剪贴板历史

**0.1.6 发布范围为本地历史。** 不需要 Apple Developer 账户，不显示 iCloud 设置、不创建 CloudKit 容器或发起云端同步。记录默认关闭，由用户主动开启。

## 先把常用复制内容留下来

1. 在主窗口打开“剪贴板”，开启顶部工具栏的“记录”。首次开启不会读取之前已经在系统剪贴板里的内容，只收集之后的新复制。
2. 复制文字、网页链接或图片。顶部搜索框与“最近／收藏”、应用筛选直接控制下方列表；左侧选条目，右侧查看内容。没有匹配项时可点击“清除筛选”。
3. 选中条目后点“复制”，再到目标应用手动粘贴。“更多”还提供纯文本复制、存到 Finder 当前目录或选择文件夹保存。
4. 在剪贴板设置中录制“打开历史面板”快捷键。全局组合默认未设置；冲突会提示，请改用其他组合。菜单栏面板也有剪贴板入口，应用菜单快捷键为 `⌘7`。

历史面板保留唤出前的应用作为粘贴目标。选中内容后可选择“粘贴到原应用／粘贴为纯文本”；搜索框回车尝试粘贴到该应用，主窗口搜索框回车只复制。上下方向键切换条目，Esc 关闭浮层。目标已退出或前台切换失败时停止，不改投其他应用；主应用 **Arc Kit** 需要辅助功能权限才能模拟粘贴，只有 Runtime Host 的权限不够。未授权时仍可复制后手动粘贴。

普通复制保留可用的 RTF，纯文本操作移除 RTF。图片保存为 PNG，文字与链接保存为 UTF-8 `.txt`；“存为 Markdown”保存原文为 `.md`，不改写内容。文件名使用 `Clipboard-时间`，重名自动编号，不覆盖已有文件。

“存到 Finder”只在点击时请求读取 Finder 最前方窗口的目录，需要系统允许 Arc Kit 自动化访问 Finder。没有可访问的普通文件夹时不会猜目标，可使用“选择文件夹保存”。这条路径不依赖 Finder 右键扩展。

## 记录范围与隐私

- **记录默认关闭。** 暂停记录不会删除历史；退出 Arc Kit 停止采集，关闭管理窗口仍保留已开启的记录。
- 记录文本、HTTP/HTTPS 链接和 PNG/TIFF 图片。文本上限 256 KiB；可保留的 RTF 另限 256 KiB。图片转换成 PNG 后最多 10 MiB、4000 万像素；不收集文件引用、HTML 文档、视频或其他二进制格式。
- 忽略隐私、临时、自动生成、Arc Kit 自身写回和远端剪贴板占位标记；默认排除 Apple 密码、钥匙串访问、1Password、Bitwarden、KeePassium。可以在设置中按 Bundle ID 增删排除应用。
- 排除策略依赖来源及应用提供的标记，不能识别所有密码或密钥；复制敏感内容前暂停记录。来源优先使用剪贴板来源标记，否则取读取时的前台应用，快速切换时来源可能不精确。
- 只合并同设备连续重复内容；不做跨设备内容去重、OCR 或自动文本转换。
- 历史正文与图片存于本机 SQLite，不使用额外数据库加密。数据目录权限限制到当前用户；完整备份也包含历史，导出前应按敏感文件管理。清理历史不会清除过去导出的备份，也不承诺磁盘安全擦除。

最近记录可保留 **1、7 或 30 天**，默认 7 天；后台维护约每分钟清理一次，保留最新 1000 条非收藏记录。收藏不自动过期。需要长期保留的片段请收藏。

## 删除与清理

“删除此条”移除选中的记录；“清理本机”移除全部本地历史和收藏，不限于当前搜索结果。暂停记录不会删除已有历史。删除与清理均需确认，过去导出的备份不会一起删除。

## 开发附录：尚未开放的 CloudKit 同步

以下是后续联调契约，**不属于 0.1.6 可用功能**。维护者先准备带 CloudKit 权限的签名版本，步骤见[交付文档](交付.md#cloudkit-build)。使用者无需自行创建开发者账户或容器，只需两台 Mac 安装相同容器、相同 CloudKit 环境的版本，并在系统中登录同一个 Apple 账户。

1. 在剪贴板设置启用“通过 iCloud 同步”。
2. 选择自动上传范围。默认 **仅收藏**；“全部允许记录的历史”会上传通过本机隐私筛选的历史。
3. 点击“连接此 Mac”并确认。首次连接把原有本地历史按所选范围纳入同步；未确认前不会上传。
4. 在另一台 Mac 同样连接。运行期间约每 60 秒增量同步，也可以点击“立即同步”。网络或配额错误会显示状态，未确认上传的变更继续保留在本机，并遵守服务器重试等待时间。

范围控制**新条目的自动上传**：已经共享的条目继续同步收藏变化与删除；从全部历史改成仅收藏，不会自动删除既有云端内容。若想移除云端条目，请使用“删除此条”。

同步只向历史库合并记录，**不会主动改写系统剪贴板**。离线时仍能记录、搜索、复制和保存文件；没有接收推送或即时延迟保证，Arc Kit 未运行时不会继续同步。

账户变化会撤销上传许可并隔离原账户记录，重新确认才能连接新账户；不会把原账户记录搬到新账户。首次连接之后产生的未绑定条目保持本地，换账户后需要重新复制才会作为新记录进入当前账户。完整数据恢复后同步开关关闭、许可撤销，需再次连接；恢复本身不会上传内容。

### 云端存储契约

- CloudKit **private database**，自定义 zone `ArcKitClipboard`；按当前用户与账户分区，不使用公共库、业务服务器或跨 Apple 账户分享。
- Record type `ArcKitClipboardItem`，record name 为条目 UUID。
- `payload` 使用 `CKRecord.encryptedValues` 存放 JSON（文本／RTF、来源、设备名、日期、收藏、修订和删除状态），schema 必须为 **Encrypted Bytes**；`image` 为 CKAsset。
- 用服务端系统字段做条件写入，冲突合并后重试。删除优先，其余变更按修改时间与修订号确定顺序；不同设备时钟偏差可能影响同时发生的收藏编辑胜负。
- 记录和增量令牌在同一 SQLite 事务提交；异常批次不推进令牌。服务端令牌过期重拉仍保留本机隐藏和删除状态。未确认的部分上传继续待重试。

CloudKit 加密字段和资产保护依照 Apple 的账户数据保护机制；不要将其宣传成所有账户都具备端到端加密。接口及字段要求见 [Apple encryptedValues 文档](https://developer.apple.com/documentation/cloudkit/ckrecord/encryptedvalues) 与 [Apple 加密示例](https://github.com/apple/sample-cloudkit-encryption)。

## 验证范围与下一步

0.1.6 候选在 macOS 27.2 完成保留数据安装：旧表及配置保持不变，记录和同步默认关闭，后台与 Finder 扩展正常。真实 UI 已验证文字／RTF 采集、普通与纯文本复制、向独立测试文档手动粘贴、搜索和收藏、链接与图片历史、图片预览、选择目录保存 PNG、`⌘7` 历史面板，以及正常退出重启后的历史保留。只使用测试内容，验收后暂停记录并恢复原系统剪贴板。

离线回归覆盖迁移、设置备份、完整恢复、隐私筛选、搜索收藏、账户隔离、冲突与删除、令牌事务、迟到回包、保留期限和文件不覆盖。中英文、深浅和窄布局使用临时夹具离屏检查。开发命令见[开发文档](开发.md#clipboard-checks)。

保留的验收缺口：

- **本地交互**：自定义全局热键的实体按键触发、浮层自动粘贴及辅助功能拒绝／恢复、Finder 自动化权限与当前目录保存，尚未完成本机验收；已验证的手动复制与选择目录保存可独立使用。
- **CloudKit**：本次不开放。后续需要维护者准备 Developer 团队、容器和匹配签名，完成 schema 的开发验证与生产发布，再用两台 Mac 验证双向新增、图片、收藏、离线重连、删除、限额错误和账户切换。
- **移动端**：本轮没有 iPhone/iPad 应用；后续另做手动收集／分享扩展与历史查看，不承诺 iOS 后台持续读取剪贴板。
