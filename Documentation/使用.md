# 使用与故障处理

本文描述当前功能入口与操作边界。版本变化见[版本说明](版本说明.md)，构建与安装见[交付](交付.md)，已知限制见[规划](规划.md)。

## 安装和授权

完整应用固定安装在 `/Applications/Arc Kit.app`，包含主应用、Runtime Host 和 Finder 扩展。首次使用从“首页 → 权限”处理所需权限，普通开关和重新检测不会自动申请 TCC 授权。

| 项目 | 用途与处理方式 |
| --- | --- |
| 辅助功能 | Runtime Host 控制窗口、修改滚动、处理手势与拖拽；窗口和鼠标共用一次主体授权 |
| 菜单栏输入监听 | 显示菜单栏图标且启用窗口功能时需要；主应用只读点击，锁定点击前的目标应用，与 Host 辅助功能分别检测，不记录键盘或窗口内容 |
| Finder 扩展 | 在系统扩展设置中允许 Finder 调用菜单；修复注册不代替用户启用 |
| 后台运行 | 系统登录项中允许 Runtime Host 运行；获准不代表必须常驻 |
| 登录启动 | “系统设置 → 通用”控制主应用登录启动，等待系统批准时保留用户选择 |
| 自动化 | 执行需要控制其他应用的操作时，由系统按目标请求；普通打开终端与新建窗口/标签的要求不同 |
| 文件访问 | 按导入、导出或 Finder 文件操作的实际目录请求；没有涵盖所有位置的统一“已授权”状态 |

macOS 可能将权限归属显示为 Arc Kit 或 Arc Kit Runtime Host，应结合页面标明的执行主体核对。应用不为全部功能预先申请完全磁盘访问、屏幕录制、摄像头或麦克风权限。

## 页面与菜单栏

| 页面 | 标签 |
| --- | --- |
| 首页 | 功能状态、权限、诊断 |
| Finder | 菜单项目、新建文件、常用目录、常用应用、生效范围 |
| 窗口 | 拖拽吸附、快捷键、应用与屏幕 |
| 鼠标 | 滚动、应用规则、右键手势、高级 |
| 壁纸 | 我的壁纸、在线图库、动态图库、屏幕与播放 |
| 系统设置 | 通用、背景、数据管理、关于 |

Finder、窗口、鼠标总开关放在标签栏开头；组内直接显示设置，内容可滚动。快速查找入口在标题栏，快捷键为 `⌘K`。系统设置固定在侧栏底部，版本号显示当前实际运行版本。

设置自动保存。标题栏反馈保存结果，失败时可查看原因并重试；未提交内容不会作为后台运行配置。撤销和重做针对设置编辑，不表示能够撤销已经执行的文件或系统操作。

菜单栏首行布局为铺满、台前调度、居中、全屏，下方集中窗口、鼠标和 Finder 开关。顶部提供检查状态、设置和退出。检查状态显示处理结果，不重新加载配置。目标尚未捕获或不可调度时布局禁用；捕获失败、功能关闭或服务未就绪时，原布局区域直接显示具体原因，不会替换成其他应用。

“系统设置 → 通用 → 在菜单栏中显示”控制 Arc Kit 的菜单栏图标，默认开启。关闭后不占菜单栏位置，Finder、窗口和鼠标功能继续运行；设置保存成功后生效，重启后保留。隐藏后可通过 Spotlight 搜索 Arc Kit，或在“应用程序”中再次打开，进入通用设置重新开启；同时隐藏 Dock 图标也能这样打开。

关闭设置窗口保留功能。选择“退出 Arc Kit”会等待保存并注销 Host；如果无法完成停止，会保留应用并报告原因。

## 检测和诊断

首页区分配置、权限、连接和实际运行。未检测、连接中、过期或未收到回包不等于未授权。Finder 仅启用时 Host 可以按需休眠，不应以没有 PID 判定故障。

“重新检测”刷新运行与注册证据；“服务就绪”“连接就绪”“监听中”只代表对应检查通过，不保证真实文件结果、滚动手感或窗口布局。实际问题要同时核对操作结果。

Finder“技术详情”使用独立窗口，底部固定复制和关闭；支持 Esc、`⌘W` 和系统关闭按钮。重复打开复用窗口，关闭后不会因迟到回包重新弹出。

“修复注册…”只用于注册异常，执行前确认，会重新注册并重启 Finder；不主动启用被用户关闭的扩展。正常启动不会自行重启 Finder。诊断报告统一在“系统设置 → 数据管理”导出，包含摘要与脱敏日志，不上传、不包含数据库或媒体内容；报告不声称采集了全部 Finder 系统日志。

## Finder

在“菜单项目”选择要显示的功能并行内排序。**新建文件、使用应用打开、常用目录的选择框保留在这里**；三个资源详情标签只管理条目，不再设置重复的总开关。具体条目还须启用且可用，空菜单自动隐藏。

- 新建文件：选择内置模板或导入自定义模板，设置名称、扩展名及显示位置。模板使用对应软件图标，软件不可用时使用文件类型图标。
- 常用应用：添加应用并选择条目显示方式；菜单子项显示应用名和图标。未安装的应用不会生成可执行菜单。
- 常用目录：添加可访问的目录，按配置展示目录及允许的下级内容；也用于文件整理目的地。入口缺失时同时检查菜单选择框、条目开关和路径可访问性。
- 终端：使用一个子菜单，默认终端优先。Terminal 新建窗口，iTerm 可新建标签；普通打开与新建操作不重复出现在首层。

公开版内置文本、代码及空白 Word / Excel / PowerPoint 模板；Pages、Numbers、Keynote 和 WPS 文件需自行导入模板。从开发版升级后，已撤下的内置模板不会出现在 Finder 菜单，可在设置中删除失效条目并重新导入自己的文件。自定义模板和原文件不会被移除。

### 目标规则与云盘

| 场景 | 使用的目标 |
| --- | --- |
| 窗口空白处 | 本次窗口目录，不沿用上一组选区 |
| 侧边栏目录 | 被右键的目录 |
| 工具栏菜单 | 优先本次选区，无选区才使用本次目录 |
| 单个文件夹 | 新建到该文件夹，终端进入该文件夹 |
| 单个文件或文档包 | 终端进入父目录，文档包按文件处理 |
| 多选 | 仅显示支持整批处理的动作，不回退成某个目录 |
| 缺少明确目标 | 不执行依赖目标的动作，不猜另一个前台窗口 |

默认观察 Home 与独立 iCloud Drive 根。**iCloud 首页与子目录的原生右键菜单曾实测不出现，当前仍不承诺可用。** 可以使用 Finder 工具栏的 Arc Kit 入口；若按钮未显示，可在 Finder 自定工具栏中查找。系统仍可能不给工具栏提供目标，此时菜单会提示不可用，不能据按钮存在认定云盘文件操作已支持。

网络卷、外置目录、未下载云文件和系统保护位置受可访问性及 Finder 回调限制。Arc Kit 不接管云同步，不自动下载占位文件。不要将 `~/.arc-kit` 数据根放进云盘；这与操作云盘中的普通文件是不同事项。

预览只展示菜单布局，不执行动作。已打开菜单保持原目标，配置改变后请重新打开菜单。后台会再次检查模块、条目和高风险授权；已开始的操作不因取消开关自动回滚。

### 文件操作边界

批量重命名先预览、确认再执行，短时撤销会检查原文件身份和冲突。复制或移动到其他位置会选择目标目录，取消不执行。彻底删除、脚本、锁定等高风险工具须显式开启，彻底删除仍单次确认。

移入文件夹、解除文件夹、压缩及隐藏其他项目要求选中项来自同一目录。冲突名称不会直接覆盖，解除文件夹不穿透符号链接、应用或文档包。任务失败时尝试恢复已移动项目，无法完整恢复会报告位置。

压缩保留目录本身与扩展属性，符号链接作为链接保存；多选可能需要额外临时空间。图片转换和图标提取生成新文件，冲突时编号，不覆盖原文件。

同一时刻只执行一个 Finder Worker，任务上限为 120 秒。忙时明确拒绝，不静默排队；超时或断线可能导致结果未知，应先核对目标文件再决定后续操作。现有回滚不保证强杀进程或断电后的自动恢复。仅 Finder 开启时 Host 空闲约 15 秒退出，冷启动期间可稍后重新打开菜单。

## 窗口

支持布局快捷键、拖拽吸附、显示器顺序和应用规则。窗口动作绑定捕获的具体窗口，窗口关闭、权限不足或无法调整时明确失败，不改选其他应用。跨屏与恢复位置仍可通过对应动作入口使用，菜单栏紧凑网格不重复摆放这些按钮。

“台前调度”将窗口放在当前显示器可用区域的右侧 85%，左侧留 15%，再应用窗口间距。它是手动布局比例，不开启、关闭或检测系统台前调度；窗口最小尺寸可能使布局无法完成。可在快捷键标签为此动作录制组合。

快捷键冲突、AX 实际不可用和窗口类型不支持分别处理。只看到辅助功能授权开关打开，不足以证明某个窗口能执行布局。

## 鼠标

滚动使用全局参数：平滑、反向、速度和时长。高级参数控制横向、临时加速、临时禁用平滑的修饰键、倍率和刻度步长。普通滚轮按步长处理，高分辨率输入按原始距离处理；有原生 phase 的触控手势放行。

| 应用规则 | 行为 |
| --- | --- |
| 使用默认参数 | 使用“滚动”和“高级”中的最新已提交参数 |
| 单独设置 | 使用该应用的参数 |
| 不启用增强 | 放行原始事件，不应用 Arc Kit 的平滑、反转、加速或修饰键转换 |

“应用规则”分成两组：“未单独设置的应用”决定其余应用是使用默认参数，还是不启用增强；“应用单独设置”中的每一行优先决定该应用如何滚动，只有选择“单独设置”才在行内显示参数。移除规则后，该应用回到第一组选择的行为；空列表不会自动扩大增强范围。应用名称旁显示真实应用图标，Bundle ID 只在悬停时提供。每条规则下方的“说明”可直接编辑、换行或留空，用来记录设置用途；自动保存，随设置导出与备份保留，不影响滚动行为。

规则按实际接收事件的应用匹配。右键手势有独立开关，不受滚动应用列表约束；鼠标总开关关闭时两者都停用。规则优先级不受说明字段影响。

默认提供“UU 远程 → 不启用增强”规则，按 `com.netease.uuremote` 匹配。控制端的 Arc Kit 原样放行发给 UU 的滚轮，不再先做反转、平滑、加速或消耗修饰键；被控端应用仍按其自身的 Arc Kit 配置处理，避免两端叠加。预置说明为“UU 远程自带滚动翻转，避免重复翻转。”可自行修改或清空，之后不会自动补回。该规则不是 UU 软件内部的方向开关，也不影响右键手势。

新安装自动添加，旧安装首次升级时仅补充缺失规则，保留已有 UU 自定义配置。可在“鼠标 → 应用规则”改为使用默认参数、单独设置或直接删除；删除后按未单独设置应用的行为处理，重启和后续升级不会重新添加，导入设置也保留导入的规则列表。显式重置全部配置会恢复预置规则；恢复引入此规则前的完整数据库备份，会执行一次对应升级迁移。远程软件版本、控制端及被控端设置都会影响方向，实际效果以目标应用为准。

未感到生效时，在首页诊断查看输入、放行、输出与降级记录，并观察实际页面移动。输出帧增加不证明目标应用消费成功；USB、蓝牙、触控板、唤醒及多屏仍需分别确认。

## 壁纸

“我的壁纸”管理导入的图片和视频，支持收藏、排序、预览与移除。卡片打开独立详情，关闭后继续浏览原位置；相同内容重复导入可复用或修复本地副本。

“在线图库”混合展示已启用的 Wallhaven、Wikimedia Commons、Bing、Lorem Picsum 内容；“动态图库”汇集 MotionBGS、NASA 和自定义视频订阅。渠道管理可保存开关、添加或移除订阅。各渠道独立分页、错误与重试，不因一个渠道失败清空其他结果；关闭渠道不删除已下载素材。

卡片标明来源和清晰度。图片以原图长短边分档，竖图等价，超宽图不会只凭长边标成 4K；视频使用来源标注，缺信息显示未标注，不拿缩略图尺寸冒充原始清晰度。素材归属与使用条件以来源页为准。

详情支持下载到图库、设为桌面或应用背景，显示下载进度并可取消；可读的本地副本优先复用。也可导入 HTTPS 图片直链，不解析任意网页。部分来源目录或签名下载地址会失效，应刷新来源后重试。

### 视频订阅与循环编辑

视频订阅为 HTTPS JSON 目录，`version` 为 1，包含 `name` 与 `items`；条目包含稳定 `id`、`title`、来源页、预览及 `variants` 下载版本。完整格式见[订阅示例](动态壁纸源示例.json)，示例只引用素材，不分发视频文件。订阅与重定向按受支持的 HTTPS 访问规则校验。

视频使用原生播放器预览，选清晰度后下载；本地视频可截取区间、调整速度并导出新壁纸，原文件保留。桌面与应用背景视频静音循环，隐藏或不满足播放条件时暂停，缺失媒体显示可恢复错误。

### 多屏与桌面状态

本地、在线和动态素材使用同一选屏流程。多屏时选择一块、多块或全部当前屏幕，确认后才应用；单屏可直接选定。手动应用目标和自动轮换范围分别设置，下载中接入的新屏幕不会自动加入，所选屏幕断开时不会改投其他屏幕。

“屏幕与播放”展示屏幕排列、每屏分配与状态，支持单屏更换和缩放。静态壁纸写入后最多等待约 3 秒回读，未确认时保留待确认状态，不能把接口返回成功当成屏幕已显示。真正失败只尝试恢复已操作的屏幕，原壁纸文件缺失时报告无法恢复。

不承诺一次应用覆盖每个独立 Space。其他壁纸应用可能竞争桌面设置；多屏视频、切换 Space 与长期能耗的验收状态见规划。

## 系统设置

“通用”管理菜单栏图标、Dock、登录启动、语言、外观、减少动态效果、Finder 隐藏文件及截图位置。语言支持跟随系统、简体中文和 English；应用与 Finder 菜单按已保存选择更新，系统授权窗口仍使用 macOS 语言。隐藏文件和截图位置属于系统外部状态，截图位置不进入 Arc Kit 配置备份。

英文切换入口为 Settings → General → Language。保存失败时沿用已提交语言；原有操作反馈可能保留产生时的语言。用户名称、路径和在线素材原始标题不翻译。应用内切换无需重启；更改 macOS 首选语言后重新启动 Arc Kit。不同应用菜单与长文案的覆盖情况见[规划](规划.md)。

“背景”管理 Arc Kit 窗口的系统、柔光、图片或视频样式，与桌面壁纸分开。选择尚无素材的图片/视频样式时先选择文件，取消保留原状；也可从图库设为应用背景。图片和视频可调不透明度、模糊与界面遮罩，“恢复清晰”保留素材并重设显示参数。

柔光提供琥珀、松雾、暮色、极光、冰川、墨金六款主题，分别配有深浅色版本。卡片选择立即预览并自动保存；上方完整窗口预览可切换深浅外观。常用调节为色彩浓度、阅读遮罩与静止/缓慢/标准速度；展开“自定义主题”可修改光晕、薄雾或光带构图，分别编辑深浅配色（底色与 2–4 个光源色）、光线范围及位置，调整粒子、细颗粒和轻微指针视差。

“从图片提取配色”更新当前主题正在编辑的深色或浅色配色，取色后不依赖原图。主题可以命名保存、复制、收藏、删除；收藏通过卡片右键菜单切换，个人主题优先显示收藏项。导入导出使用最大 64 KB 的 Arc Kit JSON 主题配方，包含深浅配色、构图种子、运动速度、粒子与颗粒参数；阅读遮罩、色彩浓度和指针视差属于应用偏好。“恢复当前主题”清除该主题的临时微调，“撤销调整”恢复本次外观编辑起点，不撤销个人主题的保存、删除或收藏；“重置背景”重设当前背景与自动规则，回到系统背景，保留已保存的个人主题与收藏。个人主题最多 60 个，纳入应用配置备份。

主题切换可选择手动、跟随应用深浅外观、按日间/夜间时段。手动选主题或修改主题配方会临时覆盖自动规则，点击“恢复自动切换”后继续按规则选择；时段支持跨午夜，按本地时间计算。删除自动规则引用的个人主题时，日间改用琥珀、夜间改用墨金。

本地、在线和视频壁纸详情的底部操作统一为左侧“设为应用背景”、右侧蓝色“设为桌面壁纸…”。桌面操作继续先打开显示器选择，不直接应用到所有屏幕。

多屏、不同显示器与长时间运行的体验仍需持续验收，验证范围见[规划](规划.md)。

自定义背景贯穿侧栏、正文与标题栏，窗口按钮保持原生位置。减少透明度时使用纯色，隐藏、不活动或减少动态效果时暂停相关动画。替换失败保留旧背景；重置背景不改桌面或原始文件。媒体使用应用自己的副本，移除引用后的磁盘回收见下文。

“关于”展示版本、[Arc Kit 官网](https://arc-kit.com)、GitHub 入口及隐私说明。更新使用 Sparkle，默认自动检查官网与 GitHub 上的签名订阅；可关闭自动检查，手动点击“检查更新”，或开启自动下载并在退出时安装。Sparkle 校验订阅与安装包的 Ed25519 签名，完成安装与重启；当前包未使用 Apple Developer ID 签名或公证。旧开发版需要先从官网下载并手动安装这一版，后续才能使用自动更新。在线壁纸与订阅仍按其设置访问相应素材服务。

## 数据管理

所有数据位于 `~/.arc-kit/`，不要将数据库移到云盘、网络卷或通过符号链接重定向。页面直接展开备份与恢复、存储空间、诊断、重置与卸载。

| 入口 | 范围 |
| --- | --- |
| 导出全部数据 | `.arckitbackup` 目录包：数据库、模板、素材及哈希清单，含图库、背景和订阅配置 |
| 仅设置与模板 | JSON：通用、Finder、窗口、鼠标设置与托管模板，不含图库和背景 |
| 恢复备份 | 同一入口选择数据包或 JSON，按文件识别范围，执行前确认 |
| 最近设置恢复点 | 设置导入或恢复默认前保存的设置与模板，只用于设置回退 |
| 存储空间 | 查看分类占用、打开数据目录、刷新占用；缓存清理保留素材、配置、更新包、锁与运行凭证 |
| 导出诊断 | 状态摘要和脱敏日志，不含数据库或用户文件内容 |
| 恢复默认 | 重置通用与三个功能的设置，保留壁纸和背景；设置恢复点保存失败则不重置 |
| 卸载 | 注销后台与扩展、移走应用；数据是否移除由用户明确选择 |

导出范围不影响恢复识别。完整恢复先等待写入、停止后台，校验数据库与资源，保留旧数据库恢复点再替换；操作结果留在数据管理页。任务期间阻止并发备份、恢复、重置、撤销和卸载。内部数据库快照不再提供手动按钮。

日志滚动保存，内部自动快照最多保留 7 份；诊断副本按 10 份/30 天清理。外部导出的包及手工升级回退备份不由该规则清理。从图库移除或切换背景只解除引用，不立即删除媒体，避免破坏其他 Space 或备份。卸载移除数据时，如当前桌面仍引用素材会拒绝清除。

配置格式不匹配的 JSON 会明确拒绝，不静默重置。旧文件存储迁移和应用无法启动时的离线恢复见[交付](交付.md#storage-cutover)。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 常用目录没有出现 | 菜单项目勾选、具体条目启用、路径可访问，以及是否在云盘受限位置 |
| 已保存但菜单没更新 | 关闭旧菜单重新打开，再看当前扩展快照与 Host 连接 |
| 点击后无反应 | 对照命令接收、执行结果及实际文件，不只看扩展回应 |
| 窗口选错或无法调整 | 查看捕获目标与失败原因，不能用其他前台窗口代替原目标 |
| 滚动无效果 | 检查总开关、作用范围、规则、输入和输出，再看实际目标应用 |
| 后台出现多个进程 | 区分一个 Host、临时 Worker 与系统 Finder 扩展；额外 Host 记录 PID、路径和版本 |
| 关闭窗口后后台还在 | 这是保留功能；需停止时正常退出应用 |
| 数据占用没有随移除下降 | 素材当前保守保留；缓存清理不是素材删除 |
