# Agent 会话：备份、查看与恢复

在侧栏打开 **Agent 会话 → 来源与保护策略**，添加 Codex 数据目录，然后点击“备份全部”。需要持续保护时打开“自动保护新增和变化的会话”。默认来源列表为空、自动保护关闭，不会在安装后自行读取个人会话。

首版支持 Codex 的本地 `legacy` 与 `paginated` JSONL 会话，包含 `sessions/`、`archived_sessions/` 及父子会话关系。原生恢复目前限定经过验证的 **Codex CLI 0.163.0**；其他版本仍可保留格式可识别的原始记录，恢复前需完成对应版本适配。Claude Code 与远端同步尚未接入。

## 保护哪些数据

- 原样保存完整记录边界内的会话日志，包括模型可见的消息、工具请求、结果、分页序号及压缩记录。
- 分页子会话另存仅属于该会话的 SQLite 历史投影；投影进度必须与日志边界一致，缺失时标为部分备份，需在 Codex 打开历史后重新备份。
- 保存会话标题、项目目录、创建与活动时间、原生置顶和归档状态，以及父子关系。
- 内嵌图片随原始日志保存。`local_images`、`local_image` 引用的本地附件，只从来源目录或用户另行授权的附件目录读取；每个附件最多 32 MB。
- 原生链接型附件保留数据库引用，云端内容不下载，标为未打包附件。缺失附件、半行日志及采集期间变化分别形成“部分备份”，不伪装成完整副本。
- 不读取 `auth.json`、API Key、账号配置、远控注册或整个用户目录。不备份项目代码、正在执行的终端、运行队列和目标自动续跑状态；代码回退仍使用 Git 或文件备份。

来源目录必须是用户明确选择的普通目录，不沿符号链接查找文件。多个来源以独立 UUID 区分，相同 session ID 不会在会话库中混为一条。移除来源只停止跟踪，不删除已经保存的副本。

## 自动保护与版本

关闭设置窗口后继续保护；退出 Arc Kit 停止。无需额外后台进程、Agent Hook 或模型调用。

FSEvents 通知合并 30 秒后检查变化，每 5 分钟补扫一次，启动和系统唤醒后立即检查。稳定且已完整保护的文件只检查文件大小、修改时间与原生元数据，不重复读取正文。变化的会话创建新版本；子会话变化会为父会话建立同批检查点，未变化的父日志复用已有资产。

默认保留 30 天版本历史、快照与附件容量上限 5 GB；派生的正文索引另占应用数据库空间，可在“数据管理”查看总占用。始终保留最新版本、最后一份完整版本、固定版本及其父子引用闭包。Arc Kit 内部元数据恢复点仍引用的资产也不会清理。达到容量上限时停止新增并报告，不删除最后一个副本来腾空间。源会话删除不传播到备份。

单份日志最多 256 MB，单个快照和便携包解压后最多 512 MB。较大的导出应分批选择；超过限制会明确失败。

## 查找与导出

会话列表默认按来源、项目以及标题、路径、ID 筛选，支持多选。选择一条会话后，右侧查看版本、原始消息与折叠的工具记录；“在此版本中查找”仍只搜索当前版本。版本旁的锁形按钮将该版本固定保留。

要找“在哪次会话里讨论过这个问题”，将搜索框右侧从 **会话信息** 切换到 **消息正文**，输入原文中的词句：

- 搜索范围是已经保护的所有版本中的用户与助手正文，包含已移除来源留下的备份；工具输出、系统上下文、附件内容和尚未备份的会话不参与正文搜索。
- 中文短词、英文大小写和重音均可匹配。输入按字面词句查找，`OR`、引号和 `%` 不作为搜索语法执行。
- 来源、项目筛选同时生效；正文模式的项目列表包含历史版本中的旧项目，切回会话信息时会清除不再适用的项目选择。每个会话显示最新的匹配版本、正文上下文和备份日期；点击结果直接打开该版本并滚动到匹配消息，旧版本的内容不会被最新版本替代。
- 每次最多显示 80 个会话，超过时提示缩小搜索范围。首次搜索会在后台为旧备份补索引；清空或修改查询会取消旧结果，失败可以重试。

正文模式清空查询后恢复会话列表；切回“会话信息”可继续查看未备份来源。有筛选条件时，手动备份仅处理当前筛选结果及其父子关联会话。窄窗口保持列表、详情两级切换，详情顶部可返回搜索结果。

**导出加密备份**会自动包含所选版本所需的父子会话，生成 `.arckitsessions` 文件：

- 使用系统 Apple Encrypted Archive，scrypt 口令派生、AES-CTR 加密与 HMAC 认证，LZFSE 压缩。
- 口令至少 12 个字符，导出完成前进行完整解密回读。
- 口令不写设置、钥匙串或日志；遗失口令无法恢复。将口令和备份分开保管。
- **导入加密备份**以一个数据库事务加入会话库，不自动添加来源，也不写回 Codex。

同盘副本用于防误删。防磁盘损坏需要将加密包另存到外置磁盘或其他独立存储位置。

## 恢复到 Codex

1. 选择会话及版本，点击 **恢复到 Codex**。
2. 选择目标 `CODEX_HOME` 和 Codex CLI。目标可以是新的空目录，也可以是已有数据目录。
3. 项目位置改变时使用“映射项目”，核对每条会话是新增、相同还是冲突。
4. 退出使用目标目录的全部 Codex 客户端，再勾选确认并点击“验证并恢复”。

相同日志默认跳过；不同内容默认跳过，勾选“替换冲突会话”才替换。部分备份需单独确认缺失数据。恢复不会自动打开终端或重放历史工具调用。

恢复先在隔离 `CODEX_HOME` 中使用官方 app-server 读取、恢复和回读历史。主会话使用原生 resume 重建；子会话遵守原生限制，不独立 resume，而是恢复其专属历史投影后用 thread/read 回读。验证使用固定空工作目录与不可用的本地上游，不使用原账号认证。随后将所选会话行合入目标数据库的候选副本；其他会话和目标账号配置保持原样。原始日志、分页投影、标题、置顶、归档、附件引用和父子边一起处理。项目映射只修改结构化工作目录字段，不替换历史文字中的任意路径；分页投影同步重定位日志字节边界。必要时原生客户端创建并删除一个无模型请求的临时会话，以初始化当前版本的分页 schema。

开始写入前检查目标数据库是否被进程打开，并再次检查确认后的目标日志是否变化。操作过程中必须保持目标客户端关闭。

### 恢复被中断时

目标目录中的 `.arc-kit-recovery/<操作 ID>/` 保存写入日志及替换前的文件。中断后再次选择同一目标，会显示“回退中断的恢复”。保持 Codex 关闭，先回退，再开始新的恢复。

成功后的恢复点不自动删除。确认新会话可用后，可自行保留或移走整个恢复点目录；不要在恢复过程中改动它。

## 与 Arc Kit 数据管理的关系

- **仅设置与模板**包含来源与保护策略，不包含会话正文。
- **全部数据**包含会话索引与原始快照，恢复后只影响 Arc Kit 会话库，不自动写回 Codex。该目录包沿用原有未加密格式；页面明确提示隐私范围和预计体积，需要加密副本时使用 Agent 会话页导出。
- 完整应用备份、恢复、卸载与退出先停止调度、等待会话任务结束。普通备份不会暂停窗口或鼠标功能。
- 恢复默认设置关闭自动保护并移除来源配置，保留会话库；卸载并移除数据会连同本机会话备份一起移走。
- 清理缓存不删除会话版本。诊断导出不包含会话正文或备份文件。

## 实现位置

`Sources/Features/AgentSessions/` 持有适配器、备份库、恢复器与 UI。配置使用 `SettingsEditor` 和主应用单写连接；`agent-sessions-v1` 迁移创建来源、版本与任务记录。当前 AppSettings schema 为 28，旧 JSON 配置不兼容；旧完整数据库包在隔离副本中迁移。

`agent-sessions-search-v1` 在同一 SQLite 中创建派生正文索引，不增加配置字段。索引按不可变资产复用，备份或导入与版本记录在同一事务发布；旧库仅建空索引，第一次搜索从已保存快照补齐。三字符及以上查询使用 FTS5 trigram 缩小候选，短中文直接匹配派生正文，均以字面包含复核。版本轮换后无引用资产回收会级联清理索引。停止、退出或数据恢复会取消搜索并等待索引写者结束，不读取用户默认 Codex Home。

原始快照位于 `assets/agent-sessions/`，以不可变资产存储。版本索引、资产引用和最多 100 条任务结果位于 `app.sqlite`。发布版本前先完成文件落盘和资产登记；完整应用备份校验版本与资产的路径、大小和引用。便携导出与原生恢复读取前校验备份资产摘要。

## 开发验收

```sh
# 必要行为回归；只使用临时目录
swift test --filter AgentSessionTests

# 编译后，在全新目录验证真实 Codex 存储与恢复
swift build --product ArcKitApp
python3 Build/Scripts/check-agent-sessions.py \
  --output .build/agent-session-acceptance

# 离屏检查真实页面，不打开系统窗口、不注册 Host
.build/debug/ArcKitApp --agent-sessions-render .build/agent-session-render

# 需要交互调试时手动运行
.build/debug/ArcKitApp --ui-debug --agent-sessions
```

原生验收脚本在隔离目录启动 Codex，模型请求仅到本地 HTTP 替身；生成 legacy、paginated、归档及合成子会话数据，实际执行加密往返、项目路径映射、原生历史回读与冲突替换，检查其他会话没有被改动。产物为输出目录下的 `recovery/acceptance.json`。它验证存储/恢复合同，不测试真实模型能力。

必要回归覆盖记录半行、分页序号、路径边界、批量导入与索引事务失败、错误口令/篡改、版本保留、源删除、跨会话历史正文定位、短中文与字面查询、索引补建、生命周期暂停及中断回退。安装版 UI、日常个人会话的原地恢复和跨物理机器迁移需要各自授权后实测；不会用本地隔离验收代替这些结果。
