# 小工具：输入法

> 0.1.6 新增。默认保留全部现有输入源，由用户选择要移除的项目。

在 **小工具 → 输入法** 勾选要保留的输入源，取消不需要的项目，再点击 **“应用更改”**。可以保留一个或多个输入法，也可以保留 ABC 等英文键盘；默认勾选全部现有项，不预先替用户移除任何输入源。

## 自己选择保留清单

1. 打开 Arc Kit 侧栏的“小工具”；也可按 `⌘8`，或在 `⌘K` 搜索“输入法”“ABC”。
2. 取消勾选不需要的输入源。这些项目会标记“将移除”，其余项目保持不变。同一输入法的父项和全部已配置模式合为一个复选项。
3. 至少保留一个当前会话可用的输入源。若准备移除英文键盘，先确认保留的输入法能输入英文。
4. 点击“应用更改”。没有更改或没有可用的保留项时，按钮不可用；有效更改会先保存本机恢复点，再写入并回读配置。

例如，同时保留 ABC 与拼音，就勾选这两项，取消其余项目；想只用某个第三方输入法，则由用户自己取消其他输入源。列表中没有想用的输入法时，先在 macOS 中安装并启用，再回来刷新。系统入口见 [Apple：更改输入法设置](https://support.apple.com/zh-cn/guide/mac-help/mchl84525d76/mac)。

“当前会话已启用”来自系统启用清单，下方“已配置的输入源”来自保存的偏好，两者可能不同。每项分别显示“当前会话已启用”“当前会话未启用”或“会话状态未确认”；系统重复返回身份、名称、启用状态、可选择状态及布局名称集合完全相同的记录时，按同一个输入源处理；去重后仍未匹配或匹配不唯一时不推断为停用。同一输入法有多个已配置模式时，任一模式可用即标为已启用。勾选仅表示保留，不会启用或切换输入法，取消勾选也不会立即改变当前会话。普通刷新保留未应用的勾选；如果系统输入源列表已变化，则重新载入当前清单，避免把旧计划套到新配置上。

- **配置已写入**：偏好回读一致，但当前会话与保留清单尚未确认一致。方便时自行注销并重新登录，再回到工具刷新。
- **当前会话与保留清单一致**：配置和当前会话都符合用户选择。

工具不自动注销或重启 `cfprefsd`、输入法进程。

## 恢复处理前配置

点击 **“恢复处理前配置”**，恢复本次处理前的输入源列表、选择和历史。若系统菜单没有立即刷新，重新登录后检查。恢复点保留到恢复成功；准备再次调整清单时，先恢复上一次处理。

若期间在 macOS 中新增、删除或重新排列了输入源，Arc Kit 不覆盖不同的新列表。可以点击“保留当前配置”，确认放弃旧恢复点；这一步不改动系统配置，下次处理会重新备份。写入失败会尝试回滚，无法确认回滚时保留恢复点并明确提示。

## 保留什么，修改什么

只修改 `com.apple.HIToolbox` 当前用户、任意主机域中的三个列表：

- `AppleEnabledInputSources`
- `AppleSelectedInputSources`
- `AppleInputSourceHistory`

保留所有勾选的键盘布局，以及所选输入法的父项和全部已配置模式，包括输入法自己的英文模式；仍有效的选择与历史保留原顺序，已移除的引用一并清理。保留 `Non Keyboard Input Method` 条目，例如字符／表情面板和长按选字。不修改 `AppleCurrentKeyboardLayoutInputSourceID`、Fn／地球键、快捷键、登录界面或其他用户的设置，不删除任何系统或第三方输入法文件。安全输入与底层键盘布局继续由 macOS 管理。

恢复点为本机 `~/.arc-kit/runtime/input-source-recovery.plist`，权限为 `0600`，原子写入并同步到磁盘后才允许修改系统。它属于系统操作恢复记录，不是 Arc Kit 的第二份设置，不加入可跨机器导入的 SQLite／JSON 备份。此功能不增加 AppSettings 字段、Host endpoint 或常驻任务，也不申请辅助功能、输入监控或完全磁盘访问。

## 适用条件与验证

输入源清单使用 Apple SDK 的 Text Input Source Services，调用位于主线程；模式匹配使用 **Bundle ID + InputModeID**，不将 InputSourceID 当作模式 ID。子模式与所属输入法都已启用，才计入当前会话可用项；停用的父输入法下仍标记为启用的子模式不计入。显示与应用前复核使用同一套去重及匹配规则，重复登记不会使可用输入法变成不可用，也不会重复显示名称；同一身份出现启用状态或可选择状态冲突时拒绝作为可用保留项。键盘布局通过原始名称及所属 bundle 的本地化名称表匹配，去重后匹配仍不唯一时不作为可用保留项。写入使用 Core Foundation Preferences，拒绝无法识别的记录、空键盘列表和同名 ByHost 覆盖。

HIToolbox 的这些偏好字段不是稳定的公开输入法管理契约，系统更新可能恢复或重写输入源；工具不做后台反复覆盖。刷新发现列表变化时，会显示冲突，而不是继续宣称“已精简”。
