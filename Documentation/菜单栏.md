# 菜单栏图标收纳

**当前版本：0.1.5 / build 87。** 收纳名单与系统排序分开保存：⌘ 拖动只改顺序，已选图标仍可正常收起。管理页提供“编排图标”和“查找图标”两个入口。

## 配置空闲自动收起

打开“菜单栏 → 更多设置”，使用“空闲后自动收起”开关控制此功能，并通过“等待时间”调整时长。默认开启、默认 **5 分钟**，可按 1 分钟步长调整为 **1–60 分钟**。配置自动保存，重启后保留；收纳主开关关闭时不执行自动收起。

开启后，展开图标或选择“显示全部”，连续达到设定时长没有键盘、鼠标或触控板操作，就会自动收起。在任何应用中操作都会重新计算空闲时间；自动收起后仍可点击左侧三点展开。关闭自动收起只停止计时及未完成的自动请求，不影响手动展开／收起，也不主动展开已经收起的图标。

首次启用、再次展开、修改等待时间，以及显示器／Space／唤醒恢复完成后，都按当前设置重新等待完整时长，不沿用此前的空闲时间。休眠和环境恢复期间暂停；正在应用排列、取用图标或录制快捷键时不抢占操作。收起失败会恢复全部并保留错误提示，等待手动操作，不循环重试。

主应用仅查询当前登录会话的输入空闲秒数，不监听或记录按键内容；已收起、停用及退出后撤销计时。开关与时长经统一设置提交成功后才生效，保存失败不会改变运行行为。继续使用既有收纳名单和原生收起流程，不改变图标排序。

## 在管理面板编排

1. 打开“菜单栏 → 编排图标”，开启“隐藏不常用图标”。
2. 在“常驻”和“收纳”两区之间拖动图标，或点击行右侧的切换按钮。同一应用的图标一起跨区，区内可分别排序。
3. 在同一区域拖动调整顺序；列表从上到下对应系统菜单栏从左到右。右键“向左移动／向右移动”提供同样的排序操作。
4. 点击“应用排列”更新真实菜单栏。应用前可“撤销更改”，应用后可“撤销上次应用”。

两区表示图标的收纳归属：展开时收纳区图标仍可显示，点击组合入口左侧的三点可手动收起。编排区数量只统计已识别的可编排项；系统管理项和无法确认身份、位置的项目单独显示为只读，不猜测对象。

搜索时仍可逐项切换区域；清空搜索后拖拽排序。草稿不会自动应用。若在面板外改变排列、应用重启或显示环境改变，重新读取后再应用，避免旧草稿覆盖新的系统状态。

撤销记录只保留本次运行的最近一次应用，同时记录名单与实际修改的位置。名单保存失败不动排序；排序写入失败时补偿本次名单提交。撤销前重新核对身份和目标当前值，只恢复这次实际修改的键；目标已被其他操作改动时拒绝覆盖。

编排目前需要 macOS 27。顺序保存在 macOS 的位置表，不复制到 SQLite。是否收纳单独保存在 Arc Kit 的 SQLite 设置中，并纳入设置及数据备份。不重启第三方应用，不模拟鼠标输入，不需要屏幕录制权限。读写系统位置表失败时明确报错；“查找图标”和“显示全部”保持独立可用。

仍可使用系统 ⌘ 拖拽调整菜单栏；这种操作只改变顺序，不会更改已经保存的收纳名单。行右侧按钮只改变收纳归属，不移动原生图标；在编排列表中拖动才同时指定顺序。使用编排面板设置归属，不再依赖分界位置。刘海屏空间不足时，图标可能已进入 macOS 自身的溢出菜单；“显示全部”只恢复 Arc Kit 本次隐藏的应用，不强制改变系统的溢出判断。

## 一个组合入口，左右分区操作

三点与品牌标志合成同一个菜单栏项目，不再创建两个独立状态项：

- 点击整体内部的左侧三点，直接展开／收起收纳图标。
- 点击右侧品牌标志或右键，打开原功能面板。
- ⌘ 拖动时作为一个整体移动，不会插入其他图标，也不触发收纳。
- 图标始终保持三点，不在箭头、眼睛等符号之间切换。
- 悬停提示“展开收纳图标”或“收起图标”；辅助功能同时提供当前状态。
- 切换进行中只暂停左侧动作，右侧仍可打开面板。

右侧品牌标志打开原生快捷面板，仅保留窗口、场景、鼠标、Finder、壁纸及设置等工具。“菜单栏图标”整块已移除，包含状态、管理和查找按钮；图标编排与查找继续从主窗口“菜单栏”页面进入，⌘K 与既有快捷键保持可用。收纳失败在组合入口的悬停提示及主窗口反馈。

开启收纳时显示左侧开关并保留品牌入口；关闭收纳后撤除开关，品牌仍按“系统设置 → 通用”的原偏好显示。开关只是操作入口，不是排列边界；哪些应用收纳仍由编排页决定。macOS 27 不再创建内部排列锚点。

组合入口保留原品牌的系统位置，只清理已退役的独立开关位置键，不调整其他应用。三点和品牌共用一张图片及一个标准状态栏按钮；菜单仍交给 AppKit 原生跟踪，不自行摆放替代浮窗。

菜单栏标志采用彩色：品牌拱形使用珊瑚橙—玫紫渐变、细边高光和暖金断角，三点继续使用 Lucide ellipsis，以暖珊瑚色配合。标志按菜单栏尺寸绘制标准／Retina 两套位图，不再使用系统单色模板；深浅背景保持原色。组合图仍为 38 × 18pt，关闭收纳后的单品牌图仍为 18 × 18pt，左右点击边界、整体拖动与系统位置不变。应用内的大尺寸品牌资源不随之替换。

彩色品牌带有缓慢掠过的流光：每轮以 20fps 播放 2 秒，然后静置 6 秒。只移动轮廓内的高光，三点、图标尺寸和位置均不动。主应用使用缓存位图原生换帧，GIF 仅用于预览，不作为菜单栏播放资源。

在“系统设置 → 通用”开启“减少动态效果”，或开启 macOS 的“减少动态效果”，图标立即回到静态彩色版。打开菜单、收纳切换、入口隐藏、退出、休眠、息屏及切换用户时暂停；恢复后重新开始一轮，不补播离开期间的动画。是否动画不影响点击、搜索、收纳及自动收起配置。

build 75 的直接隐藏机制保持不变，不再用占位制造系统 `《`。常驻图标本身放不下时，macOS 仍可能提供系统溢出入口。

## 查找并操作图标

“查找图标”沿用独立清单，不要求开启收纳。按应用名或项目说明搜索，点击行内“打开菜单”或“点按图标”；无原生动作的项目显示“仅查看”。缺少权限时，为 Arc Kit 主应用开启辅助功能，再重新读取。

清单按名称排列，不代表系统顺序。清单总数表示已读到的项目，不是当前隐藏数量。编排页的两区和排序使用经过身份匹配的系统位置记录，不复用搜索清单的名称排序。

菜单请求只发送一次。关闭页面、切换到快捷面板或应用／屏幕变化会使旧引用失效；超时不自动重放。同一图标需要再次操作时先刷新。

## macOS 27：直接隐藏应用图标

收起会暂时关闭所选应用的系统“允许在菜单栏显示”状态；“显示全部”、停用和退出恢复 Arc Kit 本次修改的项目。用户原本在系统设置中关闭的项目保持关闭。图标不被挤进溢出区，不额外触发系统溢出箭头，也不使用会影响隐私指示灯和通知中心的考试模式。

系统显示状态按应用管理。同一应用的多个图标一起收纳或常驻，排序仍可逐项调整。输入法菜单使用独立的系统显示开关，允许编排和收纳；时钟、控制中心等固定系统项保持只读。收纳归属以保存的应用名单为准，不从任何分界位置或坐标猜测。应用或撤销排列前先恢复图标。

macOS 27 不再创建内部排列锚点，也不再把位置数值当作收纳归属。系统位置与 SQLite 名单各有唯一职责；即使系统拖动重算所有位置数值，收纳名单仍保持。系统注册表中归属不唯一或夹带其他应用的条目不写入。

### 输入法菜单与 SCVPN

编排页将搜狗的系统菜单显示为“输入法菜单 · 搜狗拼音”，可移入收纳或常驻。收纳的是同一个系统输入法菜单：切换到其他输入源后仍按此归属显示；不会停用输入法、改变输入源列表或快捷键。隐藏后编排页保留该项，仍能移回常驻。

SCVPN 等 root 应用只要具有唯一系统位置键，就可编排和收纳，不要求读取其受限的内核启动时间，也不重启应用或更改 VPN 配置。搜索中的原生菜单操作仍要求可验证的进程启动身份，缺少时保持仅查看。

### 退出与异常恢复

先把本次修改的应用及输入法菜单目标写入 `runtime/menu-bar-visibility.json`，再修改系统允许状态。独立恢复子进程登记主进程退出事件后才允许收纳；正常退出、崩溃或强制结束主进程都会触发恢复。再次启动也处理未完成清单。恢复逐项合并当前系统注册表，不覆盖位置表；失败条目保留，用户可点“显示全部”重试。

普通应用隐藏时 AX 清单仍可发现项目，“查找图标”不增加收纳前提。输入法菜单隐藏后系统会撤除 AX 项；编排页仍保留它的收纳记录，要打开原生输入法菜单需先显示全部。系统禁用显示和原生菜单动作是不同能力，实际菜单取用仍需按应用验证。显示器、Space 和睡眠变化继续保护性恢复；深度区及普通区几何筛选不开放。

### 直接隐藏验证

独立临时应用在 `/Applications` 注册后，系统允许状态的 false/true 写入已由实际截图验证为消失/恢复，隐藏时 AX 清单仍可发现它。正式收纳 session 已用独立临时图标验证异常退出恢复。build 75 安装后，通过真实管理面板重复收起／显示全部；三块屏幕截图确认收起后无额外溢出箭头，正常退出恢复图标，重启后可再次收起。品牌快捷面板的直接点击仍未自动验证：工具无法定位系统托管的状态项窗口。历史分段实验不作为新机制的验收证据。

## macOS 13–26：离屏分区

这些系统保留已有的常驻、普通收纳和可选深度收纳路径，目标系统实机验收仍待完成。原生排列为：

```text
深度图标 | 不可见深度锚点 | 收纳图标 | 不可见左边界 | 常驻图标 | 不可见右边界
```

“收起”请求收起普通区和深度区；快捷键切换仍可只展开普通区，“显示全部”恢复所有区。日常操作使用品牌左侧显示／隐藏按钮，设置页保留恢复入口。

新增收起前等待两次一致的可见边界，变更后确认完整快照及离屏边界，每次等待最多约 1 秒，只重读、不重发动作。占位宽度为最大显示器宽度加 100pt。无法确认时原生 driver 撤回本次宽度变更；设置页或控件请求失败后，管理服务按恢复策略显示全部。

普通区筛选要求发现前后的屏幕、边界和原生代次一致，且属于面板目标显示器。跨界、错序、宽度未稳定、显示器不匹配和同高度屏幕的歧义坐标均不猜归属。没有凭据时数量显示“—”，不显示假零或回退到全部图标。

普通区取用只展开普通区，发送动作前再次读取原对象的位置和当前分区。图标移入深度区或边界失效时拒绝并要求刷新，不能因为搜索命中而暴露深度区。

## 搜索并取用原生图标

无需开启收纳，即可在“查找图标”页读取与搜索图标，或从 ⌘K 打开“搜索全部图标”快捷面板；这些手动入口不创建分隔线或注册热键。全局快捷键有独立开关，搜索快捷键同样不需要收纳；分隔控件仍随收纳开关启停。面板出现在指针所在显示器，按应用名、状态项描述或 Bundle ID 搜索；上下键选择、回车取用、Esc 或点击外部关闭。输入法组合状态和文本编辑修饰键不会触发图标动作，原生控件保留自己的键盘处理。

面板随结果数量调整高度，上沿和搜索框固定；异常状态保留足够空间显示原因。悬停选择不驱动滚动。搜索面板排除本进程自有控件，避免占位项目充满清单。

管理页与快捷面板使用不同的展示模型，共享一个带所有者令牌的原生会话。面板接管后旧页面不能取消新请求；离开管理页会取消尚未发送的页面请求，迟到发现结果不会回填。成功行消费自己的令牌，失败或超时使相关会话失效，不自动重放；管理页不重新弹窗抢焦点。

发现过程在线程池读取 AX，主线程准备进程和屏幕快照、接收结果。取消、刷新或关闭后，旧结果不能回填；会话只在内存中持有本次 AX 引用，不写入 SQLite。

选择图标时核对会话 UUID、PID、内核进程启动时间、Bundle ID、辅助功能权限和屏幕快照。全图标入口直接向原来的 AX 对象发送一次 `AXShowMenu`，否则使用 `AXPress`，不再预先展开整条菜单栏。若有尚未完成的布局事务，则先取消该事务并释放它的占位；稳定的收起状态不受单项点按影响。不猜坐标、不启动替代应用。令牌在发送前消费；超时可能已经执行，不能自动重放，也不重新弹出面板抢走菜单焦点。再次打开时保留未解决反馈。

系统接受 AX 请求不等于菜单已经显示。第三方菜单的实际结果、离屏/刘海项取用及键盘交互仍需实机验收。单项请求本身不会展开或收回菜单栏，空闲自动收起独立计时；如目标不支持隐藏状态下取用，由用户明确展开后再操作，不自动重试。

## 编排身份与写入边界

原生位置键以 `status:<bundle-id>::<autosave-name>` 标识项目。AX 标识能够精确对应位置键时按精确项匹配；应用只有一个活动图标、系统也只有一个候选位置键时才采用唯一匹配。多个匿名图标、重复位置或不完整发现不合并为一个“应用图标”。编排核对唯一系统位置键和前后进程身份；root 应用不可读的启动时间不阻止编排，原生菜单取用仍要求完整启动身份。

`MenuBarArrangementModel` 保存内存草稿。应用前重新发现图标，核对进程身份、原有归属和相对顺序，再按最新位置计算移动项的插入位置。普通徽标宽度变化不因数值偏移而误报用户重排。`MenuBarSystemPositions` 合并最新表，只更新明确移动的 `status:` 键，其他应用、系统模块及自有分界保持原值。系统位置表属于 macOS 27 平台适配，结构不可识别时停止编排，不回退成仅修改面板列表。

拖放负载只有一次性随机令牌，不传原生位置键。异步落点核对本次令牌、当前模型与目标项目；外部文本和失效会话不变更草稿。只读项目不会获得拖放或移动动作。

## 快捷键

在“菜单栏 → 更多设置”中单独开启全局快捷键，再录制搜索、收起／展开或显示全部。关闭收纳时，搜索键继续可用；另外两项保留组合但不注册。收起／展开也可从 ⌘K 调用，与菜单栏按钮使用同一状态，连续触发以最后一次为准。点击录制框或用 Tab 聚焦后按回车，再按所需组合；至少包含 ⌘、⌃ 或 ⌥，支持字母、数字、方向键与 F1–F12。Esc 取消，Delete 或右侧停用按钮关闭该快捷键。三项不能使用相同组合；与其他应用冲突时会显示注册失败，不抢占已有快捷键。

录制期间暂停本功能的全局快捷键，退出录制后恢复已保存的组合，避免录制动作触发收纳栏。主应用使用 Carbon 注册热键，不监听键盘文本、不增加 Host endpoint。仅保存成功后注册，冲突报告原始 OSStatus，不覆盖其他应用的组合。停用、退出和数据恢复会注销，旧注册 ID 不能触发新绑定。

## 权限、存储和恢复

- 状态项、搜索面板和热键都由主应用拥有，不新增常驻服务或 Runtime Host endpoint。配置只推进 data revision，不重连窗口/鼠标 Host。
- `AppSettings.menuBar` 使用主应用统一 schema；当前配置版本为 32。旧 JSON 契约直接拒绝。
- `menu-bar-management-v1` 和 `menu-bar-shortcuts-v1` 迁移为旧 SQLite 补充默认关闭的功能及快捷键；`menu-bar-custom-shortcuts-v1` 将旧预设一次性转为可编辑的按键组合，保留原组合与启用状态。`menu-bar-independent-shortcuts-v1` 从旧收纳开关继承快捷键的原启停状态，新增切换键默认关闭。配置提交失败不改变原生控件。
- `menu-bar-collection-membership-v1` 给旧 SQLite 增加收纳名单，仅在首次迁移时导入仍能识别的旧分区；之后不再从位置推断归属。旧分区已失效时，在编排页重新选择收纳项目，不回滚系统顺序。
- `menu-bar-auto-collapse-v1` 给旧 SQLite 补充自动收起开关和等待分钟数，默认开启、5 分钟；不覆盖已有选择，不推进 Host 运行代次。两项配置纳入设置及完整备份，时长只接受 1–60 的整数，不为缺失字段保留 JSON 兼容分支。
- AX 探测和搜索需要 **Arc Kit 主应用**的辅助功能权限，不能使用 Runtime Host 授权代替。探测不截屏、不打开第三方菜单、不弹出授权申请；未获授权时显示设置入口。
- `showMenuBarIcon` 保存显式显示偏好；收纳开启时仍保留唯一组合入口，关闭收纳后按该偏好显示品牌。
- 应用启停使 AX 清单失效，但不改稳定收纳状态；Space/显示器变化恢复本次隐藏状态或旧系统占位，并独立推进恢复代次。旧任务不能在恢复后重新收起。
- 休眠时恢复图标并暂停收纳及取用，迟到的显示器通知不会解除暂停；只有唤醒才重新等待稳定读数。停用、数据恢复和退出取消全部恢复任务并删除控件，旧确认结果不能重新启用服务。
- 显示全部直接恢复系统允许状态或旧系统占位；全图标搜索和取用不新增分区或稳定坐标前提。稳定窗口只限制新的收起与普通区取用，超时不会自动缩小恢复入口的能力。
- macOS 保存系统排列，SQLite 只保存收纳名单，不复制位置。AX 观测 UUID、PID、坐标和数组顺序均不作为跨启动身份。
- 品牌入口不与旧系统内部锚点轮换；macOS 27 不再创建锚点。
- 显示全部可从组合入口左侧三点、设置页或快捷键执行；不依赖收起请求已经成功。
- 功能图标使用 Lucide，中英文维护于 `MenuBar.xcstrings`。

`--menu-bar-capture <新目录>` 只保存各屏顶部截图，不创建状态项或改写位置；`check-menu-bar-native.py --order <新目录>` 用两枚临时自有图标验证位置写入能否即时重排，结束清理专属位置键。

输出目录必须不存在，权限为 `0700`。旧 `--menu-bar-lab` 已删除，不维护第二套界面。

离屏导出覆盖管理页清单、搜索、行内反馈、权限、加载、空结果、失效状态，以及关闭、启用后展开、收起、再次展开、共用入口切换、再次关闭、设置面板和快捷搜索状态。同一视图中调用正式开关与切换流程；另核对内部锚点没有图片、文字和操作；品牌面板预览复用正式 `MenuBarPanel`。驱动与 AX 取用使用替身，窗口不显示，不读取真实图标或注册热键。

实机监督脚本调用 Debug 的 `--menu-bar-native-check` 或 `--menu-bar-width-check`，均在生产存储初始化前分流。正常检查在 macOS 27 连续执行两轮收起／展开，并在每轮展开后确认自有锚点及占位释放；报告记录 `noExtraControls`、`spacersReleased` 和内部锚点位置，截图按轮次保留，不覆盖前一轮。临时项目显式使用唯一 `autosaveName`，撤除时清除；**省略名称会让 AppKit 自动选名，并不能隔离系统记忆**。检查不启动 Host、不注册快捷键、不操作第三方图标。

有屏幕录制权限且系统支持时，ScreenCaptureKit 只截取各屏顶部区域，不主动申请权限；无权限则记录缺失。实机报告及只读清单含个人菜单栏信息，分享前检查。

普通检查进程内有 30 秒撤除期限和终止信号处理；监督脚本在 40 秒后只终止自己启动的子进程，3 秒后仍未退出才强制结束。正常结束先释放状态项，再记录剩余数量。实机退出码 `4` 表示占位/分区请求未确认，`124` 表示超时；`0` 不能代替截图验收，宽度实验也不宣称产品状态机通过。

安装版单图标辅助检查的期限为 300 秒，监督进程在 310 秒后终止；操作完成应创建 `finish` 文件主动撤除，协议见[开发文档](开发.md)。

Release 在存储初始化前拒绝全部 `--menu-bar-*` 参数。其他开发退出码：`1` 输出失败，`2` 参数或构建类型错误，`3` 只读探测的权限或几何未就绪。
